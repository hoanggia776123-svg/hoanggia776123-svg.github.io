## 1. Vấn đề đặt ra
Cần một trang portfolio cá nhân không chỉ giới thiệu năng lực kỹ thuật mà còn có cá tính riêng biệt theo chủ đề Sci-Fi / AI Lab, đồng thời tải nhanh tức thì và dễ dàng cập nhật qua file Markdown.

## 2. Giải pháp thực hiện
- Sử dụng Astro v5 với cơ chế zero-JavaScript mặc định để tối ưu tốc độ tải.
- Xây dựng hệ thống bảng màu Cyberpunk / Sci-Fi với Tailwind CSS.
- Thiết lập Content Collections để quản lý bài viết và hồ sơ dự án bằng Markdown có cấu trúc.
- Thiết lập GitHub Actions để triển khai tự động lên GitHub Pages hoàn toàn miễn phí.

## 3. Tính năng chính
- Giao diện 6 trang chuẩn mực: Trang chủ, Giới thiệu, Bài viết, Dự án, Phòng thí nghiệm, Liên hệ.
- Tìm kiếm bài viết tức thì theo từ khóa và thẻ phân loại (tags/categories).
- Bộ lọc dự án theo công nghệ và trạng thái.
- Trang phòng thí nghiệm (Lab) với các bản demo tương tác trực tiếp.
- Tự động lọc các bài viết nháp (`draft: true`).
